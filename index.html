Conceptos fundamentales

Desarrollo web

El desarrollo web abarca la creación y mantenimiento de sitios y aplicaciones web, utilizando lenguajes fundamentales como HTML, CSS y JavaScript.

Despliegue

El despliegue de aplicaciones web es el proceso de publicar y poner a disposición de los usuarios los desarrollos creados en entornos de producción seguros.

Colaboración

El trabajo colaborativo mediante sistemas de control de versiones permite a los equipos coordinar cambios, gestionar ramas e integrar código de forma eficiente.

DAW Project Hub

Un espacio para aprender a desarrollar, publicar y mantener aplicaciones web.

Desarrollado como práctica de Git y GitHub
